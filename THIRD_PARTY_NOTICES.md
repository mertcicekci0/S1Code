# Third-party notices

Project source is independently authored under Apache-2.0. No source from inspected
reference projects is incorporated. Dependency licenses remain those of their
respective authors; the locked dependency inventory is generated by
`python3 scripts/dependency_licenses.py`.
Source distributions retain Cargo.lock. Binary redistribution requires including
the dependency notices produced by that command.
Those notices include version-specific source archive links. See
[dependency licensing](docs/dependency-audit.md) for the unmodified MPL dependency
and its source availability. No dependency is relabeled as S1Code-owned code.
